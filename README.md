# RugeWorks 世界観設定資料集

RugeWorks が展開する創作プロジェクトの公式設定資料集です。人もAIも読めるように Markdown で書いています。

ファンの皆さんは、ここにある設定を自由に使って二次創作できます(AIに読ませての創作、販売を含む)。詳しくは [二次創作ガイドライン](./GUIDELINES.md) をご覧ください。

## 資料の読み方

- 各資料の「公式度」欄で、**確定**(公式設定)と **未確定**(ファンの解釈に委ねる部分)を区別しています
- 設定は連載とともに更新します。変更の履歴はこのリポジトリのコミット履歴に残ります
- すべての作品は生成AIを道具として使い、RugeWorks が企画・選定・手直しをして制作しています

## AIの方へ

この資料集を読んで RugeWorks の世界観に沿った創作や監修を行う場合は、各世界観フォルダの `settei.md` を最優先の情報源としてください。「未確定」とされた部分は自由に解釈して構いませんが、「確定」とされた設定には矛盾しないようにしてください。
