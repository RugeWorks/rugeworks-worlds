# 灯籠の都(仮題)設定資料集

版:2026-10-29 00:30(準備中)

## 世界の概要

人と妖(あやかし)が暮らす和風の都「燈京(ひのみやこ)」が舞台。妖には人に害をなすものもいれば、古くから人と共に暮らしてきた良いものもいる。夜ごと灯籠の明かりが悪い妖を寄せ付けず、人々は妖と「契り」を結んで力を借りて暮らしている。

## 歴史が分かれた理由

| 項目 | 内容 | 公式度 |
| --- | --- | --- |
| 契りの力 | 科学の発展以上に契りの力が強く、社会を動かしてきた | 確定 |
| 公家と武家 | 契りの才は家柄で決まると信じられてきたため、家柄が力を持ち続けた。公家と武家が並び立ったまま、武家による政権交代や明治維新のような大改革は起きなかった | 確定 |
| 首都 | 燈京が首都で、政治と経済の中心。かつて武家から英雄が現れ、都を燈京へ移した。帝は武家と一部の公家とともに燈京へ移った。英雄の名と経緯は未確定 | 確定(英雄の詳細は未確定) |
| 西の古都の役割 | 公家の大部分は古都に残り、儀礼と伝統の中心として影響力を保っている。古い力と陰謀が渦巻く、魔都のような都。燈京の武家と古都の公家は並び立ち、張り合っている | 確定 |
| 東と西の違い | 燈京を中心とする東の武家社会は、刀などで妖の邪気を斬って鎮める。古都を中心とする西の公家社会は、契りの力や術で妖そのものを押さえつけて祓い、従わせる | 確定 |
| 物語との関係 | 家柄に関係なく力を持つ3人の存在は、この社会の根っこを揺るがす | 確定 |

## 世界のルール

| 項目 | 内容 | 公式度 |
| --- | --- | --- |
| 灯籠 | 妖の力を用いた明かりで、悪い妖を寄せ付けない。古都に多いが、帝に従って移った公家によって燈京にも置かれている。灯籠を守る者を「灯守(ひもり)」と呼ぶ | 確定 |
| 契り | 人が妖と結ぶ約束。契りを結ぶと妖の力を借りられる。妖の本当の名「真名(まな)」を知らなければ結べない。強い契りは主に公家の力 | 確定 |
| 妖と食べ物 | 妖は人の食べ物を口にでき、お供え物を喜ぶ。甘いものを好む妖も多い | 案 |
| 弱い妖と強い妖 | 弱い妖は種族ごとに広く知られた名を持ち、庶民でも火を付ける程度の小さな契りを結べる。強い妖は一体ごとに固有の真名を持ち、真名を知らなければ契りは結べない | 確定 |
| 契りの才 | 契りを結べる才能は家柄で決まるとされている | 確定(ただし「とされている」だけで、真偽は物語の中で明かされる) |
| 無縁 | 名家の契りを持たない者全般への蔑称。弱い妖との小さな契りは、公家から見れば才がないのと同じとみなされている | 確定 |
| 鎮める(東) | 東で妖を無力化すること。武家は刀などで妖の邪気を斬って鎮める | 確定 |
| 送る(東) | 東で、鎮めた妖を滅ぼすこと。弔いの意味を込めてこう呼ぶ | 確定 |
| 祓う(西) | 西で妖を無力化すること。公家は契りの力や術で妖そのものを押さえつける | 確定 |
| 名を絶つ(西) | 西で、祓った妖を滅ぼすこと。利用価値がない妖や手に負えない妖に対して行う | 確定 |
| 妖改方(あやかしあらためかた) | 燈京の役所。妖の記録と書類仕事を担う。膨大な書類に埋もれた部署 | 確定 |
| 妖鎮方(あやかししずめかた) | 燈京の役所。悪い妖を鎮める現場の部隊で、い組・ろ組…と組に分かれる。花形の部署で、妖改方を下に見ている | 確定 |
| 書くこと・記すこと | 妖の名や術は、筆で手書きするのが最も力を引き出しやすい。スマホなどの機器でも力は使えるが、手書きに比べると効き目が弱い | 確定 |
| 名前の表記 | 名家(公家・武家など)の出身者は漢字の名を持ち、庶民はカタカナの名を持つ。名前の書き方にも身分が表れる | 確定 |
| 神社 | 公家に連なる格式の高い神社から、町の守り神を祀る小さな神社まで様々ある。神主の一族も、名家級から庶民まで幅がある | 確定 |

## 物語の軸

東では妖を鎮めて送り、西では祓って従わせるか名を絶つ。そのどちらとも違うやり方で妖と向き合う3人が手を組み、それぞれの不遇から逆転していく。灯籠の都は、妖を鎮める物語。

## 姓の付け方

| 区分 | 方針 |
| --- | --- |
| 一般の人物 | 現実にもある、ありふれた姓でよい |
| 公家・武家の名家 | 架空の姓を使う。実在する歴史上の名家(五摂家、旧華族、大名家など)の姓は使わない |
| 悪役・事件に関わる家 | 架空の姓を使い、監修で実在の姓や著名人と重ならないか確認する |
| 読みが実在の名家と同じ姓 | 字を変えて読みだけ残す姓(例:綾小燈=あやのこうじ)も使える。ただし、大量殺人や人気キャラの殺害など、読者の強い反感を集める行為をする家は、読みも変える。線引きは物語を進めながら調整する |
| 「宮」の付く姓 | 皇族の宮家と紛らわしいため慎重に使う。悪役の家や、皇族を思わせる立場の家には使わない |
| 「院」「寺」の付く姓 | 寺院名や異名に見えやすいため、姓として自然に読めるか確認して使う |
| 長さと響き | 公家・武家の名家は、長めで特徴的な姓にする。名前だけで家柄の雰囲気が伝わるようにする |

候補の姓は下の「姓の候補帳」にまとめて作り、必要なときにそこから選ぶ。
