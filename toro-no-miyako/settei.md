# 灯籠の都(仮題)設定資料集

版:2026-10-25(初版・準備中、時代設定を追加)

## 世界の概要

人と妖(あやかし)が暮らす和風の都「燈京(ひのみやこ)」が舞台。夜ごと灯籠の明かりが妖を鎮め、人々は妖と「契り」を結んで力を借りて暮らしている。

## 世界のルール

| 項目 | 内容 | 公式度 |
| --- | --- | --- |
| 灯籠 | 夜の灯籠の明かりが妖を鎮める。灯籠を守る者を「灯守(ひもり)」と呼ぶ | 確定 |
| 契り | 人が妖と結ぶ約束。契りを結ぶと妖の力を借りられる | 確定 |
| 契りの才 | 契りを結べる才能は家柄で決まるとされている | 確定(ただし「とされている」だけで、真偽は物語の中で明かされる) |
| 無縁 | 契りの才がない者の蔑称 | 確定 |
| 祓い | 妖を退ける行為。都では妖は祓うのが当たり前とされている | 確定 |
| 妖改方(あやかしあらためかた) | 都の役所。妖の記録と取り締まりを担う | 確定 |

## 物語の軸

祓うのが当たり前の都で、妖を祓わずに向き合う3人が手を組み、それぞれの不遇から逆転していく。
